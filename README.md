# Night Mesh Chat

A lightweight Flask chat with:
- Dark matrix-inspired theme (black + gold + green)
- Captcha verification before joining
- Free username selection
- Password field with no constraints
- Message cloud-fade visual effect
- Connected users shown on both sides in random distribution
- No JavaScript required for core behavior

## Run

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Then open <http://localhost:5000>.
